# Drawers Studio 🎨
**A Creative Agency Landing Page for Digital Drawing & Design Services.**

## 📋 Description
Drawers is a clean, multi-section landing page designed for a creative studio that specializes in artistic tools and drawing services. It features a complete user journey from showcasing tools and portfolios to pricing plans and contact information.

## 🚀 Key Sections Included:
*   **Services:** Showcasing professional tools (Pencils, Compasses, Rulers).
*   **Portfolio:** A filtered gallery for Photos, Web, Print, and App designs.
*   **About & Stats:** Counter section displaying achievements (Stars, Files, Views).
*   **Skills:** Visual representation of technical skills (HTML, CSS, PHP).
*   **Pricing:** Tiered membership plans (Basic to Premium).
*   **Contact:** Comprehensive contact info, including social links and office locations.

## 🛠️ Built With
*   HTML5 & CSS3
*   Responsive Design Principles
*   FontAwesome Icons (Social & Tools)
